WildTrack: National Park Species Tracking

A full-stack, database-centered web app for planning wildlife trips: search which U.S. national parks a species lives in, see where it was last spotted, and share your own sightings on a map. CS 411 (Database Systems) final project at UIUC, built by a team of four. I worked on the SQL database, Google Cloud (GCP) setup, and parts of the frontend and backend.

Code on GitHub

Features

  • Species search: by common or scientific name, filtered by category (mammals, birds, plants…) and national park.
  • Sighting records: registered users upload a species, photo, description, and location.
  • Interactive map: every sighting appears as a map marker (Leaflet + OpenStreetMap); click one for details.

Database & Architecture

  • Database: MySQL on Google Cloud SQL, with tables for users, species, national parks, park–species links, sightings, and locations.
  • Backend: Node.js + Express in TypeScript; passwords hashed with bcrypt.
  • Frontend: React with React Router and axios.
  • Images: uploads stored in Google Cloud Storage, with only the URL saved in the database.
