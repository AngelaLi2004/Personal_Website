Global Weather Explorer (R Shiny)

An interactive R Shiny app for exploring daily weather in capital cities around the world. Pick a country, city, date range, and variable to plot the trend, browse the raw data, and get an overall Weather Score for the period. STAT 385 final project, UIUC, Fall 2025.

Code on GitHub

Features

  • Custom plots: temperature, humidity, wind, precipitation, air quality, and more, over any date range.
  • Data table: filter, sort, and search the underlying records.
  • Weather Score (0–100): a custom function scoring each day on temperature (25), PM2.5 (20), humidity (15), and cloud cover, wind, UV, and precipitation (10 each).

Data & Tools

  • Data: World Weather Repository (Kaggle), daily observations for capital cities since August 2023, with 40+ weather and air-quality variables
  • Tools: R, Shiny, dplyr, lubridate, DT
